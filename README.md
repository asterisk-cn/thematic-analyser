# Thematic Analyser — テーマ分析ワークベンチ

インタビューなどの質的データを、ブラウザ上で分析するためのツールです。

**切片**（選択した範囲）→ **コード**（その切片が言っていること、切片ごとに 1 つ）→ **ラベル**（コードに付ける。階層化可能）の順に進めます。

Svelte 5（runes）+ TypeScript + Vite。パッケージ管理は pnpm。

## 起動

```bash
pnpm install
pnpm dev         # http://localhost:5173
pnpm check       # svelte-check による型・a11y チェック
pnpm build       # dist/ に静的ファイルを出力（任意の静的ホスティングで動作）
```

## 構成

- `src/store.svelte.ts` — アプリ全体の状態（`$state` クラス）と localStorage への自動保存
- `src/lib/engine.svelte.ts` — 複数メディアの同期再生エンジン
- `src/lib/parse.ts` — txt / json / srt / vtt の読み込み
- `src/lib/labels.ts` — ラベルの木構造と旧形式データの移行
- `src/lib/export.ts` — JSON / CSV / Markdown の書き出し
- `src/components/` — 画面部品（`sidebar/` は右側のタブ）

## できること

- **トランスクリプト読み込み**：`.txt` `.md` `.json` `.srt` `.vtt`
  - txt：1 行 1 発話。`[00:01:23] 話者: 本文`、`00:01:23 - 00:01:30 本文`、Otter 形式（`話者  0:03` の見出し行）を自動認識
  - json：`[{start, end, speaker, text}]`、Whisper の `segments`、AssemblyAI の `utterances`（ms は自動換算）など
- **動画・音声の同時再生**：複数ファイルを 1 本のタイムラインで同期再生。トラックごとに開始オフセット・音量・ミュートを設定
  （下部タイムラインのバーをドラッグして調整、Shift で 1 秒単位）
画面は 2 ページに分かれています（ヘッダーで切り替え）。

**① コーディング**
- **切片とコード**：本文を選択 → ポップアップで「その切片が言っていること」をコードとして書く。複数行にまたがる選択も可能
- **コード一覧**：コードをその場で書き直し、メモ。クリックで該当箇所へジャンプ＆シーク。ラベルで絞り込み（配下を含む／未付与のみ）

**② ラベル整理**
- 左：ラベル未付与のコード、中央：ラベルの木、右：選んだコードの前後の文脈（コード・メモもここで編集可）
- コードをラベルへドラッグして付ける。ラベルの ⋮⋮ をドラッグすると別のラベルの下へ入れ子に
- クリックで選択、Ctrl/⌘/Shift＋クリックで複数選択 →「新しいラベルでまとめる」「既存ラベルへ移動」。選択中のものはまとめてドラッグできる
- ラベル同士をまとめると、元の親の下に新しいラベルができる（下位→上位へ階層を積み上げていける）
- 大量のデータ向けに：ラベル・コードの検索（一致した箇所の上位を自動で開く）、すべて開く／閉じる、ラベルごとのコードは一定件数を超えると折りたたみ

- **書き出し**：プロジェクト JSON（再読み込み可）／切片・コード CSV（ラベルは階層ごとに列を分けて出力、Excel 対応 BOM 付き）／ラベルの階層を見出しにしたレポート Markdown

作業内容はブラウザの localStorage に自動保存されます。メディアファイル本体は保存されません。同じファイル名で読み込み直すと、前回の同期設定が復元されます。

## ショートカット

| キー | 動作 |
| --- | --- |
| Space | 再生 / 一時停止 |
| ← / → | 5 秒戻る / 進む（Shift で 1 秒） |
| Esc | 選択解除・ポップアップを閉じる |
| Enter（ポップアップ） | 切片を作成（Shift+Enter で改行） |

以前のバージョン（共有コード＋テーマ）で保存したデータは、読み込み時に自動で移行されます（旧テーマ → 上位ラベル、旧コード → その下の子ラベル、切片のコード文 = 付いていたコード名）。
